# Changelog

All notable changes to MKVForge. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions: [Semantic Versioning](https://semver.org/), MAJOR.MINOR.PATCH.

Every merged PR that changes the shipped app bumps the version in the same PR with `scripts/bump-version.sh patch|minor|major`, which also adds 1 to the build number and adds a stub section here. Fill it in with one line per user-visible change, under Added, Changed, Fixed, or Removed, with the PR or issue number. Docs-only and CI-only PRs don't bump.

## [Unreleased]

## [0.8.1] - 2026-11-25 (build 10)
### Fixed
- After Cancel, starting the queue again keeps Done and Done · warning rows finished and unchecked. Only the remaining Ready rows run, and the summary counts that new run (#30).
- Show in Finder opens a normal-sized window. One file is selected; several files open the Output folder with nothing selected. A missing file still shows an alert and does not open Finder (#31).

## [0.8.0] - 2026-11-24 (build 9)
### Added
- While a batch runs, the caption under the progress bar shows about how long is left, such as "About 2 minutes left" (#23).
### Fixed
- That caption no longer flashes only as the next file starts. It stays up while the file is muxing (#23).

## [0.7.0] - 2026-11-24 (build 8)
### Changed
- Split requires only an audio track. A source with no subtitles, no chapters, or neither stays Ready and warns (`No subtitle tracks found`, `No chapters found`). A source with no audio track is still an Issue and is not split (#42).

## [0.6.0] - 2026-11-24 (build 7)
### Added
- Show Ready, a bottom-bar toggle in Split and Remux (off by default, not remembered). It hides Issue rows in the table. Ready, Done, Done · warning and Failed stay visible, and the summary, Scan and Run still use the full queue (#48).

## [0.5.0] - 2026-11-21 (build 6)
### Added
- Remux: Match on MKA Name (Settings, on by default). A video pairs with an MKA when its name starts with the MKA's name, ignoring case; collisions show as Ambiguous match with a Choose Match picker; picks clear on re-scan, folder or setting change (#33, supersedes #16).

## [0.4.1] - 2026-11-20 (build 5)
### Added
- The MKVForge app icon in the Dock, Finder and About window: Design Bot's Track Clamp, an orange `.mkv` track and a purple `.mka` track joined by a steel clamp ring on a crimson plate, with hand-tuned 16 and 32 pt art.
### Changed
- `App/MKVForge.xcodeproj` is now generated by XcodeGen 2.48.0 from `App/project.yml` (its first regeneration, so every object ID changed). `App/project.yml` keeps project-wide settings under `base:` and no longer creates intermediate groups (L33).

## [0.4.0] - 2026-11-20 (build 4)
### Added
- The app window (#5): a Split | Remux mode switch, remembered folder pickers, Scan with a `Scanning… N of M` count (Esc stops it and keeps the previous rows), the queue table with checkboxes and each file's status and reason, Split/Remux and Cancel in the toolbar, the bottom bar summary and progress, Show in Finder, and the MKVToolNix-not-found banner. Keys: ⌘↩, ⌘R, ⌘., Esc, ⌘1, ⌘2 and Space.
- Quitting or closing the window during a batch asks first (#5): Finish Current File, Quit, or Cancel. Closing the window quits MKVForge.
- Settings (#5): choose a specific mkvmerge or go back to the automatic search, and turn the batch-finished notification and Dock bounce on or off (both on by default, only when MKVForge is in the background).
### Changed
- Remux accepts full MKVs in the Video folder (#5): a video file with audio or subtitle tracks is Ready with `Uses video only, ignores …` instead of an Issue, and only its video track is used.
- A chosen mkvmerge that's missing or doesn't run shows "Can't run this mkvmerge" in the window and Settings, with no fallback to the automatic search (L15). Settings lists the real search order.
- CI ad-hoc signs the app before zipping it, so testers' copies can post notifications.
- A Remux scan right after a Split no longer flags the new `.mka` files as still changing (#5, L32). Files copied in by hand keep the one-minute rule.
### Removed
- The unused `skipped` status and `CommandFlags.canClearFinished` in the core package.

## [0.3.0] - 2026-11-19 (build 3)
### Added
- Running Split and Remux in the core package (#3): one file at a time with the installed mkvmerge, exit 0 = Done, 1 = Done · warning, 2 = Failed, and the batch keeps going after a failure. Output goes to a hidden temp file that is renamed only on success and never replaces an existing file. Each file is re-checked right before it runs. Cancel finishes the current file, then stops. Per-file reasons and the batch summary use the layout contract's text. Nothing in the app window changes until the App UI phase (#5).
### Changed
- AGENTS.md, README.md and docs/LESSONS.md L19: never hand-edit project.pbxproj; App/project.yml plus `xcodegen generate` is the source of truth. AGENTS.md: existing output is never overwritten. docs/LESSONS.md: L28 and L29.

## [0.2.0] - 2026-11-18 (build 2)
### Added
- Scanning and checks for Split and Remux in the core package (#2): top-level folder scan, exact base-name pairing, every validation rule from docs/scaffold.md, `mkvmerge -J` parsing, and the Split and Remux command builders. Nothing in the app window changes until the App UI phase (#5).
### Changed
- `scripts/bump-version.sh`, README.md and AGENTS.md: `major` means a major enhancement or breaking change, not a new phase.

## [0.1.0] - 2026-11-18 (build 1)
### Added
- Project created with macos-swift-app-boilerplate.sh (#1): hybrid layout, CI with the universal macOS build, one placeholder window that shows whether mkvmerge was found, Settings, and Help > Export Debug Log. No drag and drop or Open… (folders come from Choose… buttons in a later phase).
